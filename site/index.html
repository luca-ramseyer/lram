01 · About

Calm, precise work across infrastructure, security, and software.

I work in the Security Operations Center, where I focus on incident response and day-to-day security operations. I also build automation with Azure Functions and Logic Apps to streamline recurring processes and remove unnecessary manual work.

Outside of daily operations, I build open-source tooling for analysts. My most recent project is Raml KQL, a privacy-first desktop app that runs any KQL query against as many Log Analytics and Microsoft Sentinel workspaces and tenants as you need. It gets as close as possible to querying in a Defender multi-tenant organization, without needing one.

I care about efficiency, practical value, and using technology in ways that save time for everyone involved.
